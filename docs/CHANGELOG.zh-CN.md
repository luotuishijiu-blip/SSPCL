# SSPCL 更新日志

从「本地 MOD 压缩包导入」开始，按实际发布顺序整理至「装配工坊全幅画布」版。前四个版本发布于 2026-10-09，第五个版本发布于 2026-10-10。

## 1. 本地 MOD 压缩包导入

[对应发布](https://github.com/luotuishijiu-blip/SSPCL/releases/tag/archive-20261009-local-mod-import)

### 新增

- MOD 商店增加「导入已下载压缩包」入口，支持多选 ZIP、RAR、7z。
- 导入在后台进行，自动识别 MOD 信息并安装到 MOD 池，保留原始压缩包。
- 本地导入与在线下载任务可以同时存在，导入本地文件无需请求论坛 API。

### 使用说明

- 导入后在对应游戏版本的 MOD 管理中启用。
- ZIP 使用内置解压；RAR、7z 需要系统已安装 7-Zip 或 WinRAR。
- 不含 MOD 元数据的补丁或附加文件会提示按发布帖说明安装。

## 2. MOD 启用修复、完整更新与内存概览

[对应发布](https://github.com/luotuishijiu-blip/SSPCL/releases/tag/build-20261009-mod-update-memory)

### 修复

- 修复勾选启用 MOD 时的卡顿，文件复制和启用清单写入改为后台处理。
- 启用状态按 MOD ID 判断，避免文件夹名称不同导致重复启用或误报「已经启用」。
- 改善快速连续勾选时的清单写入；同 ID 已安装时复用文件，停用只更新启用清单。

### 新增

- MOD 管理增加「论坛更新」与「本地更新」，支持从论坛发布包或本地压缩包更新。
- 核对 MOD ID、游戏版本及包内完整性后，完整替换旧版目录，避免新旧文件混杂；保留启用状态，失败时恢复旧版。
- 游戏版本不兼容时保留旧版；游戏运行期间阻止更新。
- 概览显示当前版本的 Xmx/Xms 分配值，以及运行中游戏的物理内存和私有内存占用，约每两秒刷新。

## 3. 舰船装配工坊重新开发

[对应发布](https://github.com/luotuishijiu-blip/SSPCL/releases/tag/build-20261009-loadout-workbench)

### 重构与改进

- 百宝箱中的 AI 装配按独立模块重新开发，旧实现保留作参考。
- 统一舰船图片、武器槽位和武器贴图的坐标、缩放与角度，处理炮塔、固定武器、内置武器和舰船皮肤。
- 读取原版与当前启用 MOD，提供舰船/武器搜索及兼容武器筛选。

### 新增

- 可视化手工装配、锁定槽位、锁定空槽、撤销和重做。
- 画布支持滚轮缩放、中键拖动和「适应画布」。
- 支持均衡、远程、突击、防御风格的离线规则装配，根据 OP 和长期幅能预算生成方案，考虑弹药再生。
- 支持自定义 AI 服务生成建议，经本地槽位、尺寸、类型、OP 与锁定状态校验后应用；支持取消、超时及过期结果丢弃。
- AI 密钥可选择使用当前 Windows 用户加密保存。
- 支持 `.variant` 配置导入和导出，不直接修改存档或游戏目录。

## 4. 装配工坊船插与完整数据

[对应发布](https://github.com/luotuishijiu-blip/SSPCL/releases/tag/build-20261009-loadout-details)

### 界面改进

- 舰船目录改为可拖动调宽的侧栏，可收起为装配画布腾出空间，展开时恢复宽度。
- 右侧增加「武器详解」「船插」「舰船数据」页面。

### 船插编辑

- 支持普通船插、内置/S 插及原生船插 S 强化。
- 普通船插按舰船尺寸计入 OP；新增内置/S 插不计 OP、不限制数量，适配与冲突由玩家决定。
- 手工船插选择参与撤销、重做，并在规则装配及 AI 建议中保留。
- `.variant` 导入/导出保留普通船插、永久船插、S 插及原生船插强化。

### 数据展示

- 显示结构、装甲、速度、盾效、盾弧、幅能容量、基础散幅、部署点等舰船基础数据，以及完整属性和描述。
- 显示当前配装的总护盾、总装甲、总结构每秒伤害及幅伤比，随配装变化实时更新；包含内置武器，不计导弹。
- 武器详解提供完整本地描述、单发伤害、DPS、射程、幅能、弹药与再生等属性，保留全部 CSV 参数、武器规格及存在的独立弹体参数。

## 5. 装配工坊全幅画布（2026-10-10）

[对应发布](https://github.com/luotuishijiu-blip/SSPCL/releases/tag/build-20261010-loadout-canvas)

- 画布铺满工作区，移除上下边框、深色底板和下方独立数据区，目录收起后获得全部释放空间。
- 数据缩减为右上角悬浮面板，槽位、武器和船插移入右下角装配面板；两者均可收起，完整数据按需展开。
- 根据舰船、武器和槽位范围适应画布，避开悬浮面板，保留边缘空间。
- 支持围绕鼠标缩放；手工视角在编辑、撤销和重做后保留，切换舰船重新适应。
- 点击舰船槽位自动展开装配面板；面板内滚轮不影响画布缩放。
- 将重载数据和 AI 设置收进设置菜单，修正刷新后已选武器的安装按钮状态。
- 原有船插、伤害计算、锁定和 `.variant` 功能继续保留。

## 当前使用说明

- 运行需要 Windows 与 .NET Framework 4.8，无需管理员权限。
- 装配工坊入口：选择游戏版本 → 其他 → 百宝箱 → 舰船装配工坊。
- 舰船面板展示基础数据，含已知皮肤覆盖；伤害统计为类型加权理论值。船插、技能和 MOD 动态脚本的实际效果以游戏内为准。
- 当前尚未编辑舰载机与子模块配置，相关不完整配置会被拒绝导入或导出。
- 更新日志起点之前已有的商店缓存、并行下载、整合包和游戏下载功能继续保留，不在本日志中作为新增功能重复列出。

下载与历史附件见 [发布下载](RELEASES.md)，装配使用方式见 [舰船装配工坊说明](LOADOUTS.md)。

# 舰船装配工坊

入口：选择本机游戏版本后，进入「其他 → 百宝箱 → 舰船装配工坊」。旧 AI 装配实现移入 `Compatibility/Uncompiled/LegacyLoadouts`，仅作参考，不参与编译。

## 使用

1. 搜索舰船名称、ID 或来源，选择船体。目录只读取原版与当前 `enabled_mods.json` 中启用的 MOD；皮肤继承船体并应用槽位、内置武器和 OP 的改动。
2. 点击舰船上的槽位圆点，或右侧槽位列表。右侧只列出类型、尺寸兼容的武器；双击或点击「安装武器」应用。内置武器只读。
3. 手工安装或清空会锁定槽位，后续生成保留该选择；取消勾选可以让生成器重新选择。锁定的空槽也会保留。
4. 选择均衡、远程、突击或防御风格，点击「智能规则装配」即可离线生成，并在剩余 OP 内按武器幅能补充通风。配置名、通风、电容可编辑；支持撤销和重做。滚轮缩放，中键拖动，「适应画布」复位。
5. 顶部「设置 → AI 设置」填写完整 `chat/completions` URL、模型名与密钥。只有点击「AI 建议」才发送当前船体、兼容武器与装配数据；不发送本地文件路径或存档。密钥可选择由当前 Windows 用户加密保存。取消、超时、非法返回或生成期间修改装配都会保留当前方案。
6. 拖动舰船目录右边的分隔条调整宽度；点击「收起目录」或拖到最窄处可收起，给画布腾出位置。「展开目录」恢复上次宽度。
7. 「船插」页可搜索当前启用来源的全部船插，添加为普通船插或内置/S 插。普通船插按舰船尺寸计入 OP；新增内置/S 插不计 OP、不限制数量，不过滤适配或冲突，由玩家决定。船体原生船插保留，可添加或撤销其 S 强化。撤销、重做及两种生成方式均保留手工船插选择。
8. 「导出 .variant」生成游戏配置；「导入 .variant」可载入当前船体的武器和船插配置。导入的武器默认锁定。保存普通船插 `hullMods`、永久船插 `permaMods`、S 插 `sMods` 和原生船插强化 `sModdedBuiltIns`。

## 全幅画布与悬浮面板

- 画布铺满工具栏下方的工作区，移除上下边框、深色底板与独立底部数据区域；透明画布与工作区背景融合。目录收起后释放的空间全部交给画布。
- 右上角为紧凑数据面板：OP、幅能、三类 DPS、幅伤比和基础舰船属性；配置名、通风、电容、生成说明及完整舰船数据按需展开，状态提示也放在此处。
- 右下角为装配面板：槽位/武器、武器详解、船插三个标签。槽位目录默认折叠，点击舰船槽位会展开装配面板并切回槽位/武器；完整武器描述与参数在详解标签中查看。
- 两个悬浮面板分别可收起；都收起时摘要栏变窄。面板高度随工作区调整，内容内部滚动，不互相覆盖。
- 「适应画布」按船体、槽位和已装武器贴图范围计算，预留边缘与右侧面板空间。滚轮围绕鼠标位置缩放，中键拖动；编辑、撤销和重做保留手工视角，切换舰船重新适应。窗口缩小时保持手工缩放并防止舰船完全离开可见区域。
- 面板是画布的同级悬浮控件，点击与滚轮不会穿透到画布。重载数据和 AI 设置收进顶部设置菜单。

`.variant` 不是存档文件，也不是可一键安装的 MOD。可将导出文件放入自建 MOD 的 `data/variants`，文件名与 `variantId` 一致，再由该 MOD 的舰队、市场或生成逻辑引用。游戏重新加载 MOD 后才能使用。工坊不直接修改游戏目录或存档。

当前范围：武器、武器组、通风、电容、普通船插、永久船插及 S 强化；内置武器保留在导出武器组中。舰载机尚未编辑，含舰载机的配置会拒绝导入。含 `STATION_MODULE` 的舰船可预览，无法导出缺少子模块的完整配置。武器显示静态贴图，不模拟开火、后坐力或舰船脚本。

## 数据与伤害统计

- 基础舰船摘要显示结构、装甲、速度、盾效、盾弧、幅能容量、基础散幅和部署点。右上角「完整舰船数据」保留描述、完整 CSV 属性及船体/皮肤配置，应用已知皮肤字段覆盖。
- 「武器详解」显示选中武器的本地描述、单发伤害、DPS、射程、幅能、幅伤比、弹药与再生，保留全部 CSV 属性、`.wpn` 配置及存在的弹体 `.proj` 参数。内置武器也能查看；自定义字段不丢弃。
- 配装总护盾、装甲、结构 DPS 按槽位累加普通及内置武器，排除导弹。同一武器装在多个槽位分别计算。缺少伤害类型、缺少武器定义及估算数据会标注。
- 类型倍率依据游戏附带 `DamageType.java`：动能对盾 2、对甲 0.5；高爆对盾 0.5、对甲 2；破片对盾和对甲均 0.25；能量均为 1。对结构均为 1。这是连续射击时的类型加权理论值，不含目标装甲减伤、命中率或动态脚本。
- 幅伤比 = 非导弹连续射击幅能/秒 ÷ 同批武器未加权 DPS，分子和分母使用相同射击口径。OP 旁的武器幅能另为长期射击估算，考虑已知弹药再生上限。

舰船面板显示基础数据（含已知皮肤覆盖）；船插、技能和 MOD 动态脚本的实战修正由游戏计算。船插说明中的动态占位参数保留原文。工坊不执行任意游戏脚本；实际战斗效果需要在游戏中检验。

## 模块边界

- `src/Sspcl.Core/Loadouts`：游戏文件读取、目录快照、皮肤继承、槽位坐标、兼容性与 OP 校验、离线生成、AI 建议校验及 variant 读写。无 WPF、无全局启动器状态。
- `src/Sspcl.App/Features/Starsector/Loadouts`：WPF 工作区、选中与安装操作、撤销重做、共用的画布变换、贴图加载、文件对话框和 AI 设置。
- 两种生成方式返回相同的 `LoadoutPlan`。UI 仅在结果有效且当前装配未变化时应用；原始槽位 ID 始终用于安装、显示和导出。

船体像素坐标：`x = center[0] - slotY`，`y = height - center[1] - slotX`。武器旋转为 `-angle`；炮塔锚点为贴图中心，固定武器为宽度一半、高度 3/4。船体、武器、标记使用同一画布缩放，不裁剪槽位坐标。`numFrames` 可能代表独立帧文件，因此不把首帧贴图按该数值盲目切分。

坐标和锚点依据本机 `.ship` / `.wpn` 数据，并核对了 [Ship-Editor 的船体坐标转换](https://github.com/Ontheheavens/Ship-Editor/blob/master/src/main/java/oth/shipeditor/components/viewer/layers/ship/ShipPainterInitialization.java) 与 [武器贴图锚点](https://github.com/Ontheheavens/Ship-Editor/blob/master/src/main/java/oth/shipeditor/components/viewer/layers/weapon/WeaponSprites.java)。未引入该项目代码或依赖。

## 验证

`eng/build.ps1 -Configuration Release -Target Legacy` 包括离线检查：带引号的 CSV、宽松 JSON、启用来源覆盖、皮肤、内置武器、镜像坐标与锚点、类型/尺寸、OP 上限、锁定空槽、variant 往返，以及 AI 非法结果和取消。船插检查覆盖普通 OP、多于游戏常规上限的 S 插、原生强化、撤销快照和 AI 保留；数据检查覆盖描述覆盖、全部参数及非导弹伤害倍率与幅伤比。

`dotnet run --project tests/Sspcl.Core.Forum.Tests -c Release -- --live-loadout` 只读本机 `D:/Starsector`，检查攻势级实际坐标、XIV 皮肤及 100 艘舰船的有效生成结果。其他位置可通过工坊重载查看解析提示。

`powershell.exe -NoProfile -STA -File eng/smoke-loadout.ps1 -Executable src/Sspcl.App/bin/Sspcl.exe -GamePath D:/Starsector` 检查内嵌依赖、WPF 控件、槽位点击、实际贴图层坐标与角度、手工安装、锁定、撤销重做与导出；还检查分隔条拖动、目录收起与恢复、普通及 8 项内置船插、完整武器/舰船属性与伤害标签，并离屏生成各页预览到 `release`。这些检查不启动游戏，不等同于游戏内战斗测试；外部 AI 用模拟服务验证协议，不使用玩家密钥消费额度。
